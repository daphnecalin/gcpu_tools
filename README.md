The purpose of this project is to emulate the functionality of the G-CPU (Gator CPU) used in EEL3701C at UF.  
This includes reading both assembly and mif files, and being able to view the contents of memory during/after execution.  
This doesn't include accurate behavior of the machine by clock cycle (for now).  
  
To use:  
Navigate to the project directory, and use "cargo run" in the terminal
